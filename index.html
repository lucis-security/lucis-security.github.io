What we attack

Six ways an AI app breaks. We test all of them.

01

Prompt injection

Instructions hidden in what the model reads: user input, documents, web pages, emails.

  • OWASP LLM01
02

Data and prompt leakage

What the model can be made to reveal: other users' data, secrets, its own instructions.

  • OWASP LLM02 · LLM07
03

Tool and permission abuse

Agents that call tools they should not, with more access than the task needs.

  • OWASP LLM06
04

RAG and memory poisoning

Content planted in your knowledge base or memory that steers later answers.

  • OWASP LLM04 · LLM08
05

Unsafe output handling

Model output that reaches your product unchecked: scripts, queries, commands, links.

  • OWASP LLM05
06

MCP and integrations

Servers, plugins and third-party APIs your agent trusts by default.

  • OWASP LLM03 · LLM06
